# Security policy

## Supported versions

Security fixes are provided for the latest release of clidex.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private
security advisory form:

https://github.com/syshin0116/clidex/security/advisories/new

Include affected versions, reproduction steps, impact, and any suggested
mitigation. You should receive an initial response within seven days.

The project does not collect telemetry or execute installation commands returned
by the index. Users and agents should review package-manager commands before
running them.
